Data Science and ML project from the course "Social Media Mining" of my Information and Technology's degree at "Università degli Studi di Milano (MI))"

# YouTube Trends
The goal is to study the relationships between trending creators on YouTube Italy (May 2024) and other creators on the platform, as well as their respective audiences.

Following this steps:
- **Data Gathering**: Collect data on creators from the platform.
- **Collaboration Network Analysis**: Analyze the collaboration network.
- **Audience Network Analysis**: Analyze the network between creators and their audiences.
- **Machine Learning**: Predict which creators will collaborate.
